# lumen-plans

只放 OpenSpec 文件。根目錄就是一般專案 `openspec/` 裡的內容：`config.yaml`、`changes/`、`specs/`。

程式 repo 用 git submodule 把本倉掛在 `openspec/`。單獨 clone 本倉時，請把資料夾命名為 `openspec`，或在某個程式 repo 裡跑命令。

- 專案：https://tec-tfs.tecyt.com/tfs/Training/OpenSpec/_git/lumen-plans
- API：https://tec-tfs.tecyt.com/tfs/Training/OpenSpec/_git/lumen-api
- SDK：https://tec-tfs.tecyt.com/tfs/Training/OpenSpec/_git/lumen-sdk
- App：https://tec-tfs.tecyt.com/tfs/Training/OpenSpec/_git/lumen-app
