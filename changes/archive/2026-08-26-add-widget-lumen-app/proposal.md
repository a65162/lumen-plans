## Why

在 lumen-app 落地產品規格 `add-widget`：列表印出 SDK 的 label。

## What Changes

- 列表輸出使用 SDK 的 `widgetLabel`
- 對已啟動的 API 執行 `node app.mjs` 時印出 `Demo widget — Sandbox widget`

## Capabilities

### New Capabilities

- `widget-print`：消費端列出 widget 時印出 SDK label

### Modified Capabilities

- （無）

## Impact

- 僅 lumen-app
- 產品規格變更：`add-widget`
